# 🌱 Sistema de Irrigação Automática (Simulado)

Este projeto simula um sistema de irrigação automática utilizando Python, representando o funcionamento de um sistema IoT mesmo sem o uso de hardware físico (ESP32).

---

# 📌 Objetivo

Desenvolver uma aplicação que simule:
  
	•	Leitura de um sensor de umidade do solo.

	•	Acionamento automático de uma bomba de água.

	•	Indicação de estados por LEDs.

	•	Visualização dos dados em uma página web.
	
---

## 🚀 Como Rodar a Aplicação
### abra o .py

python atividade.py

### Acesse no navegador:

http://localhost:8080

---

🎯 Funcionalidades

	•	Simulação de umidade do solo

	•	Controle automático de irrigação

	•	Interface web dinâmica

	•	Exibição no terminal (serial)
  
---

⚠️ Observação

Este projeto simula o funcionamento do ESP32
